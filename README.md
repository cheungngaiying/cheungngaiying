# Helix Guide · Digital Human for Collaborative Robots

**Helix Guide** is a virtual learning environment for collaborative robot beginners. Build your own robot workspace by dragging items, customizing your digital human, and switching views.

🔗 **Live Demo**: https://cheungngaiying.github.io/cheungngaiying/

---

## 🎯 Project Overview

Helix Guide allows zero-experience users to understand collaborative robot workstations through intuitive interactions. The project combines digital human guidance, free item placement, and drag-and-drop functionality to lower the learning curve and make robotics education more engaging.

---

## ✨ Features

### Avatar Customization
- Choose Gender (Male / Female)
- Select from 6 different faces
- Avatar appears in the scene after selection

### Item Placement
- 7 types of equipment available: Workbench, Control Panel, Robotic Arm, Conveyor Belt, Safety Fence, Warning Sign, Plant
- Each type has **4 different styles** to choose from
- Each style can be placed **up to 5 times**
- Mix different styles of the same item in the scene

### Interaction
- **Drag and drop** any item to reposition it
- **Click to select** an item, then use the **Size** and **Rotate** sliders to adjust it
- **First / Third Person** view switching

### Save & Share
- Generate a **6-letter private code** to save your scene
- Re-enter anytime using **Enter with Code**
- Share the code with others for group learning

### AI Assistant
- Built-in smart assistant to answer questions
- Ask about items, placement order, or next steps

## 🚀 Quick Start

1. Open the [live demo](https://cheungngaiying.github.io/cheungngaiying/)
2. Click **"Create New Environment"**
3. Select **Gender** → click a **Face** to confirm your avatar
4. Click any item style from the Library (e.g., "Workbench 1")
5. Use **+** and **−** buttons to adjust quantity (max 5 per style)
6. Click **"Add to Scene"** to place items
7. Drag items to reposition them
8. Switch between **First View** and **Third View**
9. Click **"Save"** to get a private 6-letter code
10. Use **"Enter with Code"** to return anytime
